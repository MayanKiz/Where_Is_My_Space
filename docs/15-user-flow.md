# User Journey

## Primary journey

```text
Open WIMS
   ↓
Choose Location
   ↓
View Live Availability
   ↓
Set Requirements
   ↓
Get Recommendation
   ↓
Navigate to Space
   ↓
Use Space
```

## Example journey

A group of four students needs a place to study.

1. They open WIMS.
2. They select the campus.
3. They request four connected spaces.
4. They prefer a less-crowded area.
5. WIMS filters currently available spaces.
6. The recommendation engine ranks valid options.
7. The user sees the recommended area and current availability.
8. The user goes directly to the selected location.

## Operator journey

```text
Sign in
  ↓
View Areas
  ↓
Check Occupancy
  ↓
Review Alerts
  ↓
Inspect Utilization
```

## Failure experience

If live information is unavailable, the interface should say so clearly instead of displaying stale data as current.
