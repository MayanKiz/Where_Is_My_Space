# Design System

## Brand

**Where Is My Space?**

### Core message

> Find your space before you reach there.

## Visual direction

The product should feel:

- Modern
- Friendly
- Intelligent
- Trustworthy
- Spatial
- Lightweight

## Suggested palette

### Primary
Soft pink / blush for the brand background and friendly visual identity.

### Text
Deep navy rather than pure black for a softer premium appearance.

### Status
Use distinct accessible indicators for:

- Available
- Moderate
- Busy
- Unknown

Status must never depend only on color.

## UI language

Prefer human language:

- “12 spaces available”
- “Moderately crowded”
- “4 spaces together”
- “Updated 20 seconds ago”

Avoid unnecessarily technical wording in the user interface.

## Cards

Use:

- Rounded corners
- Clear hierarchy
- Strong spacing
- Subtle borders
- Lightweight shadows
- Responsive layouts

## Accessibility

- High contrast
- Keyboard accessibility
- Descriptive labels
- Screen-reader friendly status
- Color-independent status communication

## Design principle

The interface should answer:

> **Where can I go right now?**

within seconds.
